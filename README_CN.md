## ✨ 核心特性
- 🤖 **通义千问 AI 引擎**：连续对话、上下文记忆、自定义人格
- 🔍 **Tavily 实时全网搜索**：精准获取最新公开信息
- 🎮 **HoYoLab / 米游社 查询**：支持国服 & 国际服账号信息
- 🎵 **多媒体支持**：YouTube / B站 解析、总结、点歌
- 🔧 **Flask 网页管理后台**：在线状态、黑名单、日志、权限控制
- 🎛️ **斜杠指令 + 前缀指令 + 可视化按钮**
- 🌐 **中英双语自动识别**
- 🛡️ **本地安全验证**：仅内网访问，管理员权限隔离
